# 🏠 House Price Prediction using Linear Regression

## Project Overview
This project predicts house prices using the Linear Regression algorithm on a real Kaggle Housing dataset.

## Dataset
- Source: Kaggle Housing Dataset

## Features
- Area
- Bedrooms
- Bathrooms
- Stories
- Main Road
- Guest Room
- Basement
- Hot Water Heating
- Air Conditioning
- Parking
- Preferred Area
- Furnishing Status

## Target
- Price

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Jupyter Notebook

## Workflow
1. Data Loading
2. Data Preprocessing
3. Label Encoding
4. Train-Test Split
5. Linear Regression
6. Model Evaluation
7. House Price Prediction

## Evaluation Metrics
- MAE
- MSE
- RMSE
- R² Score

## Result
Successfully predicted house prices using Linear Regression.
